# Asset Manifest

This game ships no third-party art, audio, font or level assets. The interface, the procedural
dungeons and every creature sprite are HTML, CSS and JavaScript drawing code licensed under
AGL-1.1. No asset is extracted or redistributed.

| Path or pattern | Type | Rights holder | License | Notes |
|---|---|---|---|---|
| `static/`, `*.py` | code (procedural levels, synthesized audio, canvas creature sprites) | AegeanWorks | AGL-1.1 | no separate assets |
| `static/js/renderer.js` | canvas sprite art | AegeanWorks | AGL-1.1 | skeleton, goblin, bat, spider, necromancer, pact wraith, skeletal archer, crypt hound, boss lich, hero and props drawn procedurally |
| `assets/**` | brand artwork and screenshots | AegeanWorks | AGL-1.1 | logo, social preview and captured UI screenshots |
